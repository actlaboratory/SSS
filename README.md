# 所得制限シミュレータ (sss)

給与所得を中心とするサラリーマンを対象に、各種手当や制度の利用条件となる所得制限の金額と、入力した条件での所得金額を比較できるWebシミュレータです。

現在は、20歳前の傷病による障害基礎年金の所得制限に対応しています。

## 環境

- Node.js: v20 以上
- パッケージマネージャ: pnpm
- ビルドツール: Vite
- 言語: TypeScript
- UIフレームワーク: React 18 + React Bootstrap

## 開発

```bash
# 依存パッケージのインストール
pnpm install

# 開発サーバーの起動
pnpm dev

# プロダクションビルド
pnpm build

# ビルド結果のプレビュー
pnpm preview
```
